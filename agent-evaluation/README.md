# 任务型助手评测实验室

新增 AI 辅助学习原型：将“回答了”拆成意图正确、任务完成和交付约束。离线规则路由调用实际本地经营工具，没有大模型 API。

## 问题与交付

单关键词、单任务路由会遗漏多意图，执行被否定的任务，或在没有记录时继续诊断。构造 36 个人工样例（24 开发、12 保留），标注意图集合、预期工具与约束；保存版本对照、CSV、失败案例和执行 trace。

## 复跑

下载完整仓库，在根目录执行（Node.js 18+，无第三方依赖）：

```bash
node agent-evaluation/evaluate.js
```

会生成 cases.json、report.json、results.csv 与完整 results.json。这里保存部分 trace 便于快速阅读；复跑能得到 72 条版本结果及完整轨迹。工具依赖同仓库 `coffee-lab/model.js`。

## 范围与下一步

输出约束只核对字段、来源和数值，不代表语义正确或模型准确率。开发与保留样例均为本练习编写，保留组不是独立业务盲测；Prompt / Skill 是设计稿，当前程序不执行模型 Prompt。后续接入真实模型后固定参数与工具轨迹，再用外部样例和人工交付质量验证。
