# 嗨皮瓜：共同开发入口

这是从腾讯云当前线上版本建立的共同开发目录。2026年10月16日首次导入的 `web/` 内11个文件，来自腾讯云 `haipigua/` 目录，经逐一校验一致。

当前线上网站：[打开嗨皮瓜](https://frost-guard-d3gw4cry5916d32c4-1503361620.tcloudbaseapp.com/haipigua/)。

## 看前端，不需要先读代码

在共同仓库根目录运行（建议统一使用 Node.js 20+，无第三方依赖）：

```bash
node haipigua/preview.cjs
```

然后打开终端显示的网址，默认 http://127.0.0.1:8877/ 。修改 `haipigua/web/` 后刷新网页，即可查看修改。这个预览只在启动它的电脑上运行；同伴可下载对应分支，使用同样命令预览。

GitHub 文件页面展示源码；本机预览或腾讯云网址展示真正可操作的网页。预览中的浏览器记录与腾讯云网站各自独立。

## 目录与边界

- `web/`：原生 HTML、CSS、JavaScript 前端，可以直接编辑，无需 npm 安装或构建。
- `preview.cjs`：本机前端预览，并把 `/api/health`、`/api/agent` 转发给本机8878服务；它自己不持有密钥、不调用模型。
- `server/`：独立的本机文本模型服务，启动方法见下文。
- `COLLABORATION.md`：前后端分工、提交与联调约定。

2026年10月17日的前端升级使用 `index.html`、`studio.js`、`studio-core.js`、`studio.css` 和四张机器人 WebP。旧 `app.js` 与样式保留作历史参考，不再由页面加载。无需 npm 安装或构建。

- `DEMO_GUIDE.md`：打开网站、三分钟演示顺序、赛事资料和奖励模式判断。
- `BACKEND_HANDOFF.md`：同伴当前提交情况、真实模型/视频/记忆/积分接口待办。
- `DESIGN.md`：四角色素材和生成规格。
- `tests/`：66项离线回归检查：本地流程27项、模型结果桥6项、客户端调用与原子保护8项、本机服务25项。
- `scripts/README.md`：真实模型的双路由、反馈、下一步调整及歧义追问评测；与离线测试分开运行。

温和、奖励、督促三种陪伴方式已可选择；督促按天、自愿，可立即退出。成长值仅为自报生成的演示待核验记录，不能抵现或抵扣费用。视频只在本机保存回看，未接入 AI 分析。

现已加入可运行的本机文本模型服务：`server/` 调用智谱官方免费文本模型，前端通过 `/api/agent` 同源代理发送原话与近期相关上下文。皮皮先理解/分流，再按需独立调用滴答、啵啵或回回；模型结果经过结构和时间校验后原子写入。每条模型记录可以展开实际调用轨迹。失败保留草稿，不自动改成本地规则冒充成功。仓库不保存密钥或真实浏览器记录。

## 使用真实免费模型

需要 Node.js 20+，不需要安装 npm 依赖。从共同仓库根目录打开两个 PowerShell 终端。

终端一启动模型服务，并按隐藏输入提示粘贴自己的智谱标准 API Key：

```powershell
powershell -ExecutionPolicy Bypass -File .\haipigua\server\start-local.ps1
```

脚本默认明确选择免费的 `glm-4-flash-250414`。2026-10-17 本机联调中，`glm-4.7-flash` 返回1305（该模型访问量过大）；这不等于密钥错误，也不需要因此改用收费模型。若要手动选择4.7，在上面命令末尾加 `-ModelName glm-4.7-flash`。直接运行 `server/run-local.cjs` 的程序默认值仍是4.7，自动化启动应明确提供 `MODEL_NAME`。

终端二启动前端：

```powershell
node haipigua/preview.cjs
```

保持两个终端开启，打开 `http://127.0.0.1:8877/#chat`。页面显示实际型号及本机服务配置状态；只有发送成功才说明该次真实调用成功。健康检查不验证账户额度或模型当前容量。服务只允许这两个免费型号，不自动切换型号或使用付费型号。密钥只留在服务进程内存，重启后需要重新输入；不要把密钥放进网页输入框、代码或提交。

完整接口、故障分类与边界见 `server/README.md`。这不是公网后端，腾讯云静态站不能直接访问你电脑的8878端口。公网发布仍需服务端鉴权、配额与部署。

离线测试（不调用外网），在共同仓库根目录运行：

```powershell
node --test --test-isolation=none haipigua/tests/*.test.cjs
```

当前66项通过。真实模型可用性和理解质量另行检查：先暂停浏览器里的模型发送，再运行 `node haipigua/scripts/evaluate-live.cjs --case route`；完整四轮去掉 `--case route`。2026-10-17修复后，四轮合成真实调用全部通过，共8次模型调用：学习/创意分流、反馈保存、下一步由10分钟缩短到5分钟、模糊时间追问。这是一次通过记录，不是稳定性保证；此前格式、日期、引用和表情错误也在联调中出现并修复。详见 `LIVE_VALIDATION.md`。完整合成结果保存在被 Git 忽略的 `haipigua/.local/live-evaluation.json`。

## 同步与发布

前端在 `frontend/haipigua` 分支持续提交，通过合并请求与 `main` 对齐。已存在的其他项目保留在仓库原目录。提交代码与更新腾讯云分别进行；本次建立开发入口不会修改现有腾讯云网站。

经团队验收需要正式发布时，将 `web/` 内静态文件部署到腾讯云的 `haipigua/` 子目录。部署路径不要选择环境根目录。
