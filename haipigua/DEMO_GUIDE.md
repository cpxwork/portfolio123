# 给参赛者的演示小抄

## 打开与使用

成品演示：在 `haipigua` 目录复制 `.env.example` 为 `.env`，填好平台/Key/型号，运行 `npm start`（或 `node server/app.cjs`），浏览器打开 `http://127.0.0.1:8877/`。页面和 API 同源，不需要另开预览。只改前端时也可在仓库根目录运行 `node haipigua/preview.cjs`。修改文件后刷新。GitHub 展示代码，这个网址展示可操作页面；它只在启动服务的电脑上可用。腾讯云生产网站需要发布负责人另行更新，不会因为 Git 提交自动改变。

首页直接输入完整碎碎念，按“递给皮皮”；Enter 发送，Shift+Enter 换行。不要先替系统分类。每段原话保留，点击“看看这次怎么理解的”检查规则是否理解对；理解错就继续说明。右上角选择今天的温和、奖励或督促方式。语音按钮需要浏览器支持和麦克风授权，不可用时用系统键盘语音输入。

“行动约定”看当前时间；“记忆口袋”修改已确认事实和默认时长、精力、基础，也能导出/导入文字备份。自由文字记忆目前仅作为记录，结构化偏好及历史反馈直接参与本地计划。视频可在反馈表单附上，25 MB 以内，本机保存回看，尚未分析；文字备份不包含视频原文件。

## 三分钟演示顺序

1. 先说问题：很多人不是没有计划，而是有许多碎片愿望；重复填表、计划不合生活、失败后难以重启。
2. 输入：“我想学画画，我是零基础，明天中午十二点试十分钟。明天上午九点到十一点有课。另外我想做一个给流浪小猫找家的小网站。”展示一段原话分给学习与创意。
3. 补充：“明天中午十二点到下午一点有课。”展示系统先追问。再说：“改到下午三点吧。”检查仍是明天。
4. 说明下面是模拟反馈，再输入：“画画只练了五分钟，有点难，因为线条总画不直。”展示回回交回皮皮。
5. 说：“画画后天中午十二点再练十分钟吧。”对比下一次实际时长与难度，说明依据哪条反馈改变；真实模型建议的比例会变化，不能预先承诺固定缩成几分钟。2026-10-17合成陶笛测试从10分钟变为5分钟，见 `LIVE_VALIDATION.md`。
6. 最后展示三种模式。虫虫先手动预览、一键清除。积分说清是不可兑换的本地体验，不把自报当成真实核验。

这是流程示范，不要把模拟反馈包装成真实用户成效。请以现场规则和实际可用模型服务为准。

GLM模式还可以沿用当前兴趣补一句：“画画刚才的建议太多了，只改成每次10分钟的一个动作，暂时不预约时间。”这应生成本次建议，不要求日期，不改已有预约、长期默认偏好或陪伴约定。对比两条消息各自的建议，说明旧消息保存的是独立快照，继续修改不会覆盖原文案。若另说一个已经确定的实验/上课时段，该忙碌事实可以保存；“如果有实验、还没确定、先别记录”不应写成忙碌。

## 怎样讲亮点

一句话：**嗨皮瓜把一段混杂的愿望，接成适合当下的一次行动；再让真实反馈改变下一次。**

三种模式是陪伴风格，不是给人贴“自律/懒”的标签。选择奖励的人多不用刻意惩罚来分流。除完成率，也记录继续使用意愿、反馈质量、计划修改次数、压力感与退出率；先作为待验证假设，别承诺提高多少效率。

四个头像本身不能证明多智能体。现在可启动 `server/` 本机服务，连接真实文本模型（AI Ping 或智谱），并展开每条回复的真实调用记录。重点展示角色收到哪些信息、调用什么工具、写入了什么、为何交给下一位，以及失败后的恢复。不要宣称已经具备真实教程搜索筛选、视频理解或永久记忆；API配置就绪不等于本次模型调用成功。

Agent 1主路由在允许tools时提供可选tools，否则使用JSON mode；遗漏时间事实的额外模型复核明确使用JSON mode、不带tools。请说清模型理解与代码校验各自做了什么，不把它包装成已经验证的原生函数调用。所有角色、复核与修复共享每轮4次调用、95秒总预算。

可复核证据包括108项离线检查，以及接入 AI Ping 之前的智谱基础四轮和五种固定合成对话记录。AI Ping 的真实型号、调用、费用和未通过项必须另看 `.local/review-evaluation.json` 与 `.local/live-evaluation.json`；没有新记录就不能说 AI Ping 已验证。原来三条失败及后续混合/假设忙碌失败都保留在 `LIVE_VALIDATION.md`，并标明修复结果。固定样例和一次网页操作不能推算泛化准确率或长期稳定性。

## 模型繁忙或额度不足时

AI Ping 的 402 表示付费模型余额不足，429 是平台限流，503 是服务器繁忙；智谱仍区分 1305（模型访问过大）、1113（账户欠费）、1000（鉴权失败）。这些都不应直接说成密钥错误或要求充值。服务只允许 `server/providers.cjs` 中明确列出的平台与型号，页面和 trace 如实显示；不会自动切换平台或型号。AI Ping 按 token 计费，现场演示应先设置 Key 固定额度和本机 `-BudgetCny` 估算停止线，保留可复核的真实运行记录。切换服务型号后刷新网页；草稿在当前浏览器会话保留。免费容量或付费余额都没有稳定性承诺，离线或录像展示要明确标注。
