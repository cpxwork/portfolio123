# 指标管理平台：产品设计练习

本作品为 **2026-10-08 本轮由 AI 辅助新创的学习案例**，业务、数据与用户场景均为模拟。它不对应任何公司的实习、访谈、上线成果或商业项目。作者需要亲自阅读、修改并能讲解取舍后，再作为自己的学习作品投递。

## 查看顺序

1. 阅读 [PRD.md](PRD.md)：场景、范围、优先级、8 项指标字典、付费转化口径、关联设计、3 类异常与 12 条验收用例。
2. 下载仓库后，在本地浏览器打开 [指标平台原型.html](指标平台原型.html)：无需安装或联网。可搜索和筛选指标，查看口径、直接依赖/下游关系，比较三种付费率，切换异常状态。
3. 阅读 [VALIDATION.md](VALIDATION.md)：已实际执行的模型规则检查及尚未验证的边界。

[model.js](model.js) 是原型的可复查数据与规则文件，须和 HTML 放在同一目录。

## 作品范围

- 8 项学习指标，数据来源定义为 3 张逻辑表。
- 3 个演示交互区：指标目录、付费口径对比、异常与验收。
- 3 类异常：分母为零、源数据延迟、口径版本不一致。
- 12 条设计验收用例；验收规则与已运行检查分开记录。
- 所有原型数值都显示为示例，不代表候选人创造的业务结果。

## 面试中应能回答

1. 为什么“当日首购用户 / 当日活跃用户”不能代替“当日注册用户的当天付费转化”？
2. 为什么退款影响净支付金额，但不反向改写历史首购事实？
3. 为什么 7 日付费转化在完整观察窗结束前不能作为最终值？
4. 指标依赖过期或口径版本不一致时，为什么不能只把异常数值正常展示？

## 简历写法边界

可以在阅读、核对并实际操作后描述“AI 辅助产品设计练习”“8 项指标定义”“12 条验收用例”“本地交互原型”。不得描述成企业实习、独立开发、正式上线、真实用户验证、业务增长或跨团队交付。

原型没有登录、权限后端、数据库查询、生产指标计算或完整图形化依赖编辑器。页面里的负责人、用户问题与排期均是案例设定；没有真实调研或研发团队。
