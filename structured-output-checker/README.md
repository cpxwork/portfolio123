# 结构化输出质量核验

2026.10.12 AI 辅助离线学习练习。目标是检查结构化摘要输出是否符合约束，定位问题字段；所有来源、摘要与输出均为人工构造，未调用模型或核实公网事实。

## 问题与规则

格式完整不代表可直接使用。检查 JSON 解析、必填字段与类型、最少数量、日期范围、来源去重和输入来源匹配；模拟 `mock://` 标识不是论文地址。

- [逐字段结果](results.json) / [CSV](results.csv)

```bash
python structured-output-checker/evaluator.py
```
